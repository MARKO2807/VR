# Horvat Innovative Labs – VR Landing Page

A high-converting, responsive React landing page for **Horvat Innovative Labs** and the **VR Classroom4You** platform. Built with React 18 and Vite.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

## Build for production

```bash
npm run build
npm run preview
```

## Structure

- **`src/App.jsx`** – Composes all sections.
- **`src/index.css`** – Design system (colors, typography, buttons, cards).
- **`src/components/`** – Section components: Header, Hero, Features, SocialProof, About, VRClassroom, Applications, TrainingHubs, Technology, Benefits, Vision, FAQ, FinalCTA, Footer.

## Sections

1. Header with logo, nav, and “Request a Demo” CTA  
2. Hero with headline, subheadline, highlights, and CTAs  
3. Social proof / partner placeholders  
4. Features (6 capability cards)  
5. About – Innovation in Immersive Technology  
6. VR Classroom4You – platform and capabilities  
7. Applications (nautical, hubs, emergency, education, promotion)  
8. VR Training Hubs – support and CTA  
9. Technology behind the platform  
10. Benefits of immersive learning  
11. Vision for the future  
12. FAQ accordion  
13. Final CTA – Request a Demo / Contact  
14. Footer – links, subscribe, copyright  

Design follows a dark theme with teal and magenta accents, matching the provided reference screenshots.
